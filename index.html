Syntax Help

1) Core Combinators

  • , = union (OR): JJ,AK
  • : = intersection (AND): AK:xx
  • ! = exclusion (NOT): AA!AAA
  • Parentheses group expressions: (AA,AK):xxyy

2) Basic Examples

  • Hold'em: AA, AK$s, AT$o, 15%, 30%-50%
  • Omaha: AA, AA$ds, AA$ss, *$np, TT-77
  • Mixed: AA:xxyy, JJ!JJJ, KK

3) Spans, Lists, and Progressions

  • Rank spans: KQJT-T987, AAJT-AA87
  • Bracket lists: [A-Q][J-T]23, [2,4,6,8,T][3,5,7,9]
  • Plus/minus progression: T8+, 664-, J[T-]

4) Macros (Supported)

  • Hold'em: $s suited, $o offsuit
  • Omaha: $ds, $ss, $np, $op, $tp, $nt
  • Rank groups: $B $M $Z $L $N $F $R $W
  • Rundown helpers: $0g $1g $2g

5) Weighting

  • AA-KK@100,QQ@50 means QQ appears half as often as AA/KK.

5.1) Percentile Profile

  • % ranges use the selected Hand ordering profile.
  • Ours = equity-vs-random combo ordering.
  • PPT 6-max = ProPokerTools 6-max evolution ordering (PLO4/PLO5 only).

6) Draw/Hand Filter Tags

  • @tp top-pair core structures (with any side cards)
  • @overpair hold'em only pocket overpair vs board
  • @2p two-pair core structures (with any side cards)
  • @set set/trips core structures (with any side cards)
  • @s straight core structures (with any side cards)
  • @f flush core structures (with any side cards)
  • @fd flush-draw core structures (with any side cards)
  • @sd straight-draw shortcut structures with 1+ outs
  • @sd4 straight-draw shortcut structures with 4+ outs
  • @sd8 straight-draw shortcut structures with 8+ outs
  • @sd12 straight-draw shortcut structures with 12+ outs
  • + on ready hands includes stronger made hands: @2p+, @set+, @s+, @f+, @tp+, @overpair+
  • + is not valid on draw tags (@fd, @sd*)
  • Legacy aliases still accepted: @straight = @s, @flush = @f, @tpplus = @tp+, @sd13 = @sd12

7) Rule Differences (Very Important)

  • Hold'em evaluation can use any legal 5-card combination from hole + board.
  • Omaha (PLO4/5/6) always uses exactly 2 hole cards and 3 board cards.

8) Board / Dead Input

  • Board accepts exact cards only (0 to 5 cards): AsKdJh, 2s3s8sTd
  • Dead accepts exact cards only: AhKs

9) Practical Ready-to-use Examples

  • (AA,KK,AK$s):15%
  • AsKs:@fd
  • AA$ds!AAA
  • AKQJ-9876$ss:20%
  • (@fd,@sd):15%
