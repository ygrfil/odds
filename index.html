Syntax Help

Core combinators: , union, : intersection, ! exclusion, and parentheses for grouping.

Quick examples: AA,AK$s, 15%, 30%-50%, AA:xxyy,JJ!JJJ,KK.

Useful macros: $s, $o, $ds, $ss, $np, $nt, $B, $M, $Z, $L, $N, $F, $R, $W, $0g, $1g, $2g.

Board input supports exact cards only, e.g. AsKdJh, 2s3s8sTd.
