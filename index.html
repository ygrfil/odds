Help & Range Guide

Poker Odds Lab estimates equity for Hold'em, PLO4, PLO5, and PLO6. A setup has a game variant, optional board/dead cards, and 2 to 6 player ranges. Start with simple ranges like AA, AKs, or 30%, then add filters when needed.

1) Quick Start

  • Choose Variant. Omaha ranges automatically use the selected hand size.
  • Enter the Board if known: AsKdJh. Leave it empty for preflop.
  • Each player starts as 30%. Edit a player range or use the quick-pick buttons.
  • Click Run Simulation. Results show equity, win, tie, loss, and matching combos.

2) Main Controls

  • Precision stop controls speed vs accuracy. Smaller CI95 targets run longer.
  • Hand ordering controls what 15% or 30%-50% means.
  • Dead Cards removes known unavailable cards from the deck.
  • Clear All resets board, dead cards, ranges, and results.

3) Player Range Tools

  • The slider under each range changes the percentile window. Example: top 30% is 30%; hands after the best 10% through 35% are 10%-35%.
  • Quick-pick buttons insert board-dependent tags like @tp, @fd, and @sd8 into the focused player.
  • The A♠ button opens the card keyboard for exact board, dead, or player cards.
  • Typing @, $, or a percent token opens autocomplete for common tags and macros.
  • The ? button beside a player explains used @tag filters. On flop+ boards it also copies the matching combo list when available.

4) Exact Cards and Card Text

  • Use rank then suit: As, Kd, Th. Suits are s h d c.
  • Board accepts 0 to 5 exact cards: AsKdJh, 2s3s8sTd.
  • Dead cards accept exact cards only: AhKs.
  • A player can be an exact hand: Hold'em AsKs, PLO4 AsKsQhJh, PLO5/PLO6 with 5 or 6 cards.

5) Range Logic

  • , = union (OR): JJ,AK
  • : = intersection (AND): AK:xx
  • ! = exclusion (NOT): AA!AAA
  • Parentheses group expressions: (AA,AK):xxyy
  • * means any hand. Empty ranges are normalized back to the default 30%.

6) Basic Ranges

  • Hold'em pairs and broadways: AA, JJ, AK, AQ
  • Hold'em suited/offsuit shortcuts: AKs or AK$s, ATo or AT$o
  • Omaha rank structures: AA, AA$ds, AA$ss, *$np, TT-77
  • Percentiles: 15% for the top 15%, 30%-50% for that slice only.
  • Mixed: AA:xxyy, JJ!JJJ, KK

7) Rank, Suit, and Pattern Syntax

  • Fixed suits use card suits: AsKs, AcKc.
  • Suit variables match suits by relationship: xx suited, xy offsuit, xxyy double-suited style.
  • Rank variables repeat ranks: RR means a pair. Most users should prefer macros like $np, $op, and $tp for rank-structure filters.
  • Rank spans: KQJT-T987, AAJT-AA87
  • Bracket lists: [A-Q][J-T]23, [2,4,6,8,T][3,5,7,9]
  • Plus/minus progression: T8+, 664-, J[T-]

8) Macros

  • Hold'em: $s suited, $o offsuit
  • Omaha: $ds, $ss, $np, $op, $tp, $nt
  • Rank groups: $B $M $Z $L $N $F $R $W
  • Rundown helpers: $0g $1g $2g

9) Weighting

  • AA-KK@100,QQ@50 means QQ appears half as often as AA/KK.
  • Weights are 0 to 100 and apply to the atom they follow.

10) Percentile Profile

  • % ranges use the selected Hand ordering profile.
  • Ours = equity-vs-random combo ordering.
  • PPT 6-max = ProPokerTools-style 6-max evolution ordering, available for PLO4/PLO5.
  • When a profile is unavailable for a variant, the selector is disabled or normalized to a supported profile.

11) Board-Dependent Tags

  • Tags need a flop or later board to describe made hands and draws accurately.
  • @tp top-pair core structures (with any side cards)
  • @overpair hold'em only pocket overpair vs board
  • @2p two-pair core structures (with any side cards)
  • @set set/trips core structures (with any side cards)
  • @s straight core structures (with any side cards)
  • @f flush core structures (with any side cards)
  • @fd flush-draw core structures (with any side cards)
  • @sd straight-draw shortcut structures with 1+ outs
  • @sd4 straight-draw shortcut structures with 4+ outs
  • @sd8 straight-draw shortcut structures with 8+ outs
  • @sd12 straight-draw shortcut structures with 12+ outs
  • + on ready hands includes stronger made hands: @2p+, @set+, @s+, @f+, @tp+, @overpair+
  • + is not valid on draw tags (@fd, @sd*)
  • Legacy aliases still accepted: @straight = @s, @flush = @f, @tpplus = @tp+, @sd13 = @sd12

12) Bombpot Odds

  • Bombpot is available for PLO4 and PLO5.
  • It uses P1 as the hero range filter; opponents are always 100% random.
  • The result table compares made-hand and draw categories by player count.
  • The same board, dead cards, precision, and hand ordering controls apply.

13) Save, Import, and Export

  • The current setup is saved in this browser automatically.
  • Export Setup downloads a JSON file with the current setup and latest result.
  • Import Setup loads a previously exported JSON setup.

14) Practical Examples

  • Top premium hands only: AA,KK,QQ,AKs
  • Top 20% but only double-suited PLO hands: 20%:$ds
  • Exclude trip aces from aces: AA!AAA
  • Suited ace-king with a flush draw on the current board: AsKs:@fd
  • Good rundown slice: AKQJ-9876$ss:20%
  • Draw-heavy flop range: (@fd,@sd8):30%
  • Percentile window with extra filters: 5%-30%:(AA,$ds,@fd)

15) Rules and Limits

  • Player count is 2 to 6.
  • Hold'em evaluation can use any legal 5-card combination from hole cards plus board.
  • Omaha always uses exactly 2 hole cards and exactly 3 board cards.
  • Exact cards cannot overlap across board, dead cards, or exact player hands.
  • If the native helper backend is offline, simulations fall back to browser workers but some live previews may be unavailable.
