Syntax Help

This app uses PPT-style generic syntax for Hold'em and Omaha ranges. Case is ignored. Ranks: A K Q J T 9..2, suits: s h d c.

1) Core Combinators

  • , = union (OR): JJ,AK
  • : = intersection (AND): AK:xx
  • ! = exclusion (NOT): AA!AAA
  • Parentheses group expressions: (AA,AK):xxyy

2) Basic Examples

  • Hold'em: AA, AK$s, AT$o, 15%, 30%-50%
  • Omaha: AA, AA$ds, AA$ss, *$np, TT-77
  • Mixed: AA:xxyy, JJ!JJJ, KK

3) Spans, Lists, and Progressions

  • Rank spans: KQJT-T987, AAJT-AA87
  • Bracket lists: [A-Q][J-T]23, [2,4,6,8,T][3,5,7,9]
  • Plus/minus progression: T8+, 664-, J[T-]

4) Macros (Supported)

  • Hold'em: $s suited, $o offsuit
  • Omaha: $ds, $ss, $np, $op, $tp, $nt
  • Rank groups: $B $M $Z $L $N $F $R $W
  • Rundown helpers: $0g $1g $2g

5) Weighting

  • AA-KK@100,QQ@50 means QQ appears half as often as AA/KK.

6) Draw/Hand Filter Tags

  • @set made trips/set now
  • @2p exactly two pair now
  • @fd flush draw (not made flush)
  • @sd straight draw (not made straight, but can become straight with one next board card)
  • @sd4 straight draw with 4+ outs
  • @sd8 straight draw with 8+ outs
  • @sd12 straight draw with 12+ outs
  • @sd13 accepted as legacy alias of @sd12
  • @flush made flush now
  • @straight made straight now
  • @tpplus pair or better now
  • @overpair hold'em only pocket overpair vs board

7) Rule Differences (Very Important)

  • Hold'em evaluation can use any legal 5-card combination from hole + board.
  • Omaha (PLO4/5/6) always uses exactly 2 hole cards and 3 board cards.

8) Board / Dead Input

  • Board accepts exact cards only (0 to 5 cards): AsKdJh, 2s3s8sTd
  • Dead accepts exact cards only: AhKs

9) Practical Ready-to-use Examples

  • (AA,KK,AK$s):15%
  • AsKs:@fd
  • AA$ds!AAA
  • AKQJ-9876$ss:20%
  • (@fd,@sd):15%
